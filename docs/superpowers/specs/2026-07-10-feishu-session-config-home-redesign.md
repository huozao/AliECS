# 飞书 ChatGPT 会话配置编辑家重设计

日期：2026-07-10
状态：用户已确认，待实施

## 背景

原「统一用户配置编辑面」设计把 bridge 规则、默认对话模式放入独立「系统配置」多维表格。用户确认新的产品边界：每个大功能未来可拥有自己的多维表格；飞书 ChatGPT 会话相关配置应全部留在原「飞书 ChatGPT 会话管理台」，其他公共配置继续合并在「系统配置」。

## 新边界

- 「飞书 ChatGPT 会话管理台」是飞书 ChatGPT 功能的配置家与运行台，负责全局规则、用户配置、群配置、会话、消息、任务。
- 「系统配置」只负责非飞书 ChatGPT 的公共配置，例如 doc-sync、T+ 导出说明、库存仓库范围。
- 旧「系统配置 / 对话模式」不再作为默认对话模式编辑家；bridge 应改读会话管理台规则表 `global-default` 行。

## 功能需求

1. 默认对话模式回迁到会话管理台规则表，字段为 `对话模式默认`，取值 `极速` / `均衡` / `高级`。
2. 新对话项目链接支持人工按群、按用户修改：
   - 群表字段：`默认新对话项目链接`、`默认新对话项目名称`。
   - 用户表字段：`默认新对话项目链接`、`默认新对话项目名称`。
   - 规则表字段：`默认新对话项目链接`、`默认新对话项目名称`，作为全局兜底。
3. 群聊项目链接优先级：当前会话记录 > 群配置 > 全局规则 > env。私聊项目链接优先级：当前会话记录 > 用户配置 > 全局规则 > env。
4. bridge 自动写入用户名/群名时不得覆盖人工改过的可读名称。仅当原值为空或仍是机器 ID 时自动补写。
5. 时间痕迹拆开：
   - 用户/群表保留人工配置和少量自动补全字段。
   - `最近名称解析时间` 只代表服务器最近一次尝试补全名称的时间。
   - 服务器读取/生效/错误痕迹后续放独立状态表或管理页，不污染配置行的人工修改时间。

## 非目标

- 不把密钥、基础设施地址、认证参数放入任何多维表格。
- 不在本次实现 Feishu 通讯录/群 API 解析；先用现有消息 metadata 补全，并保护人工名称。
- 不删除生产上的旧「系统配置 / 对话模式」表；代码切走后可人工隐藏或保留为废弃表。

## 验证

- 单测覆盖默认对话模式从规则表读取、项目链接优先级、人工名称保护。
- 后端系统配置总览不再显示「对话模式」为系统配置项。
