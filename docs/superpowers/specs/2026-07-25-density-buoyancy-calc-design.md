# 浮力法密度计算器 —— 设计说明

日期：2026-07-25
状态：已拍板，待实施

## 目标

在 hydwang.xyz 的「工具 / 计算器」分区新增一个公开工具页：输入样品在空气中的重量和在液体介质中的重量，按浮力法（阿基米德原理）算出样品密度、体积和相对密度。介质默认水，可选无水乙醇或自定义；介质密度随温度自动计算，也可手动指定。

参照物是已上线的 `/tools/ash-calc/`：同样的视觉语言、同样的「打印 PDF 报告」形态、同样的注册方式（`DEFAULT_FEATURES` + 幂等迁移）。

## 已拍板的范围决定

| 决定 | 取值 | 理由 |
|---|---|---|
| 样品数量 | 单样品快速算 | 日常用途是快速核一个数，不需要 ash-calc 那种多样品平行/极差 |
| 上浮样品 | 不做沉子输入，允许液中重量为负 | 现场做法是把上浮样品用夹具固定在液面下，天平直接读负值；公式 `m空 − m液` 天然成立 |
| 介质 | 水（默认）/ 无水乙醇 / 自定义 | 覆盖实际用到的场景，自定义兜底 |
| 输出 | 屏幕结果 + 打印 PDF 报告 + 复制文本 | 与 ash-calc 对齐，可直接当检测记录存档 |
| 默认温度 | 23.0 ℃ | GB/T 1033.1 / ISO 1183 的标准试验温度 |
| 页面标题 | 浮力法密度计算器 | 与已存在的「配方密度计算器」区分开 |
| 历史记录 | 不做 | 单样品场景价值不大，YAGNI |

## 计算模型

### 主公式（GB/T 1033.1 / ISO 1183-1 浸渍法 A 法）

```
ρ = m空 / (m空 − m液) × ρ液
V = (m空 − m液) / ρ液
相对密度 = ρ / ρ水(同温)
```

### 可选的空气浮力修正（默认关闭）

```
ρ = m空 × (ρ液 − ρ空气) / (m空 − m液) + ρ空气      ρ空气 = 0.0012 g/cm³
```

默认关闭：国标基础式不含空气浮力项。该修正的影响量级为 `ρ空气 × (1 − ρ/ρ液) ÷ ρ`，实测在 0.02%–0.15% 之间——样品密度高于介质时结果略降，低于介质时略升。开关状态写进报告。

### 介质密度随温度

用算式而不是查表插值。

- **水**：Kell 公式（1 atm），适用 0–40 ℃，误差 < 0.0001 g/cm³

  ```
  ρ(kg/m³) = (999.83952 + 16.945176·T − 7.9870401e-3·T²
              − 46.170461e-6·T³ + 105.56302e-9·T⁴ − 280.54253e-12·T⁵)
             / (1 + 16.879850e-3·T)
  ```

  校验点：20 ℃ → 0.998207、23 ℃ → 0.997538 g/cm³

- **无水乙醇**：线性式 `ρ = 0.78934 − 0.00085 × (T − 20)`，标注适用 10–35 ℃

  校验点：20 ℃ → 0.78934、23 ℃ → 0.78679 g/cm³

- **自定义**：强制手动填写介质密度

任何介质都可勾选「手动指定介质密度」覆盖算出来的值（实测介质密度时用）。

## 校验与提示

| 条件 | 级别 | 提示 |
|---|---|---|
| 输入不全 | info | 提示继续填写 |
| m空 ≤ 0 | bad | 空气中重量必须为正 |
| m空 − m液 ≤ 0 | bad | 液体中重量不应 ≥ 空气中重量，检查两个读数是否写反 |
| m液 < 0 | info | 按上浮样品固定法处理，负读数已正确纳入计算 |
| ρ < 0.3 或 > 25 | risk | 结果超出常见材料范围，复核读数与介质密度 |
| 水，T 超出 0–40 ℃ | risk | 超出水密度公式适用范围 |
| 乙醇，T 超出 10–35 ℃ | risk | 超出乙醇线性式适用范围 |
| 介质为乙醇 | info | 乙醇易挥发吸水，浓度漂移直接影响密度，建议实测后手动指定 |
| \|ρ − ρ液\| / ρ液 < 2% | risk | 样品密度接近介质密度，浮力差小、相对误差被放大，建议换介质 |
| 自定义介质但未填密度 | bad | 必须填写介质密度 |

## 实现

### 新文件

`services/public-web/tools/density-calc/index.html` —— 单文件，无外部依赖，纯静态。

结构（首版把四块内容全平铺，手机上要下滑很多，实测后重排成下面这样）：

1. **结果条**（置顶）：大号密度 + 体积 / 相对密度 / 介质密度三个并排小格 + 校验提示。手机上 `position:sticky` 吸顶，滚动和键盘弹出时密度始终可见
2. **核心输入**：介质、温度、空气中重量、液体中重量四个字段排成 2×2 网格；介质密度压成一行小字，勾「手动」才展开输入框
3. **折叠「样品信息与报告栏」**：样品名称、检测员、审核、日期、空气浮力修正开关
4. **折叠「公式与计算依据」**：本次公式代入、质量差、主公式、介质密度依据
5. **操作栏**：导出 PDF / 复制 / 重置。手机上固定在底部
6. `#reportRoot` 打印层（`@media print` 下才显示）

单样品足够简单，桌面和手机共用一套 DOM，靠 CSS 断点和 `<details>` 折叠适配，不做 ash-calc 那种双渲染层。输入框高 44px、字号 16px（防 iOS 聚焦缩放）。

无头 Chrome 实测 390×664 视口下页面总高 608px，手机端零滚动。

所有输入变化实时重算。屏幕上只渲染需要处理的提示，`good` 级别不占版面，但仍进报告。示例值用灰色 `.ex` 样式，聚焦即全选，与 ash-calc 一致。用户输入进报告前统一转义。
