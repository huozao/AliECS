# 安全基线（人和 Codex 必须遵守）

## 1. 禁止提交内容

- 真实生产数据库密码
- SSH 私钥
- GHCR Token / 云厂商 AK/SK
- S3/OSS/R2 Secret
- 任何真实用户账号密码与会话 token

## 2. 验证账号使用规则

1. 线上验证只允许使用测试账号。
2. 不在命令输出、日志、commit message、PR 描述、评论中输出密码。
3. 需要展示账号信息时，只显示用户名/角色，不显示敏感凭据。

## 3. 日志与排障输出规则

- 可输出：状态码、接口路径、健康检查结果、容器状态。
- 禁止输出：完整 `Authorization`、数据库连接串中的密码段、任何私钥全文。
- 必要时使用掩码：如 `token_len=573`、`password=<set:24 chars>`。

## 4. 发布前最小安全检查

1. 检查本次改动是否引入新的密钥型环境变量。
2. 检查文档与示例配置是否只包含占位值。
3. 检查 PR 与 commit 文本是否泄露敏感信息。
