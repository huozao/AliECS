分段灰分 / 填料半定量计算器

一、样品录入

0）报告信息（用于导出PDF，可留空）

1）统一测试条件

同一批样品默认共用同一组低温/高温分段条件，不在每个样品中重复选择。

2）样品平行输入

每个样品必须选择“基准”或“目标编号”。只允许一个基准，其余样品可自由分配为目标1、目标2、目标3等。

1）基础称重

原样净重 m₀ = W₁ - W₀
低温残留 m低 = W低 - W₀
高温残留 m高 = W高 - W₀

W低、W高分别对应页面顶部统一设置的低温阶段与高温阶段。

2）填料库如何参与计算

修正后填料量 m填料 = m高 ÷ k

k 来自填料库“高温残留系数”。例如 CaCO₃ → CaO，k=0.560；BaSO₄、TiO₂ 高温基本稳定，k≈1.000。修改填料库 k 后，计算会直接引用新值。

3）材料类型与默认模型

黑色母：单一填料 + 炭黑 / 有机组分
白色母：单一填料 + 钛白粉 / 有机组分
其他色母：单一填料 + 色粉 / 有机组分
改性料：单一填料 + 色粉 / 有机组分

黑色母可通过“低温残留 - 修正后填料”估算炭黑。白色母、其他色母、改性料中，若钛白粉/色粉与填料同样高温稳定，仅靠分段灰分不能唯一拆分两者；页面先输出可计算的粉体/填料折算结果，并提示风险。

4）差异计算

差值 Δ = 目标 - 基准
变化幅度 = (目标 - 基准) ÷ 基准 × 100%

正值表示目标高于基准，负值表示目标低于基准。

填料库中的高温残留系数 k 会被直接引用参与计算。

滑石粉、高岭土、ATH、MDH 等材料的 k 值受条件影响较大，建议按实际实验修正。
