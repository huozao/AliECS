# 项目计划

## 目标

从畅捷通 T+ 账套只读同步业务数据，先沉淀 BOM、物料、价格和成本相关数据，为后续分析做准备。

## 第一阶段

- 搭建 Python 命令行项目结构。
- 读取 `.env`，校验 AppKey、AppSecret、openToken。
- 封装统一 OpenAPI POST 客户端。
- 跑通 BOM 分页查询、原始 JSON 保存、Excel 导出。
- 为未确认接口预留模块结构。

## 后续阶段

- 从官方文档确认物料、成品、采购价格、销售价格、成本接口。
- 根据真实返回字段完善 `docs/data_fields.md`。
- 增加库存、单据、供应商、客户等模块。
- 视需要增加 SQLite 或其他本地分析存储。
